## What I've been building

**AIOS Family**

AI coaching, relationship intelligence, and briefing tools built around a shared Client Data Platform. My work spans TypeScript backends, business-tool integrations, AI features, and frontend development. The platform brings together email, calendars, CRM records, and meeting transcripts; the products use that context for cited answers, daily briefings, and meeting preparation.

**Kidneyhood AI Support**

A Python / FastAPI support agent for Zendesk and web chat. It retrieves knowledge with OpenAI embeddings and Pinecone, generates cited answers with Claude, and routes responses through a groundedness check. I also worked on durable ticket processing, evaluation tooling, and token and spending controls.

**Jira Vibe**

A TypeScript MCP server and web app that turn proposals into reviewable Jira plans. It supports document parsing, Gemini-generated artifacts, and agent-authored plans, with a separate review step before creating projects and issues.

**AIOS Scribe**

A YouTube transcription and insights product using Gemini. Work includes shared asynchronous jobs to avoid duplicate model calls, version-aware results, quality checks, budget controls, and stalled-job recovery.

**Fidelity Dashboard**

A CRM and operations dashboard that consolidates HubSpot, Twilio, Calendly, RetellAI, and n8n data into Supabase. It uses incremental sync and webhooks, with source-level logs and role-based data access.

*These are projects I've contributed to. Client source code may be private.*
